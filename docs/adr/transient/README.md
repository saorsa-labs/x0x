# Transient decisions

A new or changed decision goes in `T-<slug>.md` in this directory.

Name one target slot from A01 to A15. Write 300 to 600 words. Use about 80% ASD-STE100 style. Follow [the style guide](../../documentation-style.md).

The status stays Proposed until David accepts it. David folds it into that slot only when he asks.

After David accepts the record, its bytes stay the same. Folding does not edit that file. Add `T-<slug>.folded.md` beside it. The overlay status is Folded. It names the same target slot and the Accepted record. The lifecycle is Proposed, then Accepted, then Folded.

This directory does not count toward the 15 current ADRs.
